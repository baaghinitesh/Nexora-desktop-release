## What's New in v1.0.4

### 1. Brand New UI Redesign from Scratch
* **Left Navigation Sidebar**: Clean and modern navigation shell with quick access to Dashboard, Clipboard Sync, File Transfers, and Settings.
* **Vector SVG Icon Architecture**: Scalable, crisp SVG vector icons throughout the entire desktop experience.
* **Three-Way Theme System**: Full native support for **Dark Mode** (obsidian glass surfaces with neon cyan accents), **Light Mode** (crisp slate surfaces with vibrant gradients), and **System Default** (synced live to Windows OS preferences).

### 2. High-Performance Dashboard & Device Pairing
* **Instant QR Code Generation**: High-contrast pairing QR code with automatic local IP resolution.
* **Manual 4-Digit Security PIN**: Clear PIN display with on-demand code regeneration for manual network pairing.
* **System Health Monitor**: Live diagnostics for WebSocket (8080) and HTTP REST (3000) listening ports, connected mobile devices, and Windows Defender Firewall state.

### 3. One-Click Network & Firewall Auto-Setup
* **Windows Firewall Automation**: Integrated 1-click rule provisioning for incoming traffic on ports 8080 and 3000.
* **Network Profile Optimization**: Automatic detection and 1-click transition of active network profiles to Private for frictionless local communication.

### 4. Software Updates & Developer Credits
* **Seamless Update Engine**: Serverless GitHub update checks with real-time download progress and installer execution.
* **Official Branding**: Prominent, adaptive **Launch Your Concept** developer signature and direct support channels.

## Installation Guide

1. Download **`Nexora-Setup.exe`** from the link above.
2. Run the installer on your Windows 10 or 11 PC.
3. Launch **Nexora Desktop** — your local IP and connection QR code will appear automatically on the Dashboard.
4. Open the **Nexora Mobile App** on your Android phone and scan the QR code to connect!
