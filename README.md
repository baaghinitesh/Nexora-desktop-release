# 📱 Nexora - Universal PC Remote Control

Transform your mobile device into a powerful remote control for your Windows PC!

## 🚀 Download

**Latest Version:** [Download Nexora v1.0.0](https://github.com/baaghinitesh/Nexora-desktop-release/releases/latest)

## ✨ Features
- Mouse & touchpad control
- Virtual keyboard
- Clipboard sync
- File transfer
- Multiple connection options

## 🛠️ System Requirements
- Windows 10/11 (64-bit)
- Mobile device with network access
- WiFi connection

## 📱 Mobile App
Search "Nexora" in your app store or scan QR code from desktop app.
